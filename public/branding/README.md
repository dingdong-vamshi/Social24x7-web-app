# Official SOCIAL 24-7 artwork

Client-supplied artwork received 14 October 2026; no redrawing or generated replacements.

- `social24-7-icon-v1.webp`: lossless conversion of the 419 × 433 icon JPEG, preserving its complete canvas and aspect ratio.
- `social24-7-logo-v1.webp`: lossless conversion of the full JPEG after cropping outer white whitespace to 724 × 680 (origin 150, 144). No artwork cropped.
- `social24-7-favicon-v1.png`: 64 × 64, icon proportionally fitted with green padding.
- `social24-7-apple-touch-v1.png`: 180 × 180, same proportional fit.

Original supplied JPEGs remain in the owner's private source files; redundant copies are not committed. Versioned filenames prevent reuse of the previous browser icon. Increment the version when replacing artwork.

`Brand` owns the in-app asset references. Compact, sidebar and footer variants pair the official icon with accessible text. The full variant displays the original stacked wordmark on white. Functional chat icons are separate UI controls, not logos.
